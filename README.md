# Customer Behavior Data Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer segments, and factors influencing buying decisions.

The project follows an end-to-end data analytics workflow using Python, SQL, and Power BI to transform raw customer data into meaningful business insights and actionable recommendations.

## Tools & Technologies

* Python – Data cleaning, preprocessing, and exploratory data analysis
* Pandas & NumPy – Data manipulation and analysis
* SQL – Business analysis and customer behavior queries
* MySQL / PostgreSQL / SQL Server – Database management
* Power BI – Interactive dashboard and data visualization
* Jupyter Notebook – Data analysis and documentation

## Project Workflow

1. **Data Preparation & Exploratory Data Analysis:** Imported the customer shopping dataset, explored data distributions, handled missing values, and prepared the data for analysis using Python.

2. **SQL Analysis:** Loaded the cleaned dataset into a SQL database and performed queries to analyze customer segments, purchasing trends, loyalty, spending patterns, and product preferences.

3. **Power BI Dashboard:** Connected the database to Power BI and developed an interactive dashboard to visualize key metrics, customer behavior, and shopping trends.

4. **Business Insights & Recommendations:** Identified meaningful patterns in customer purchasing behavior and presented findings through a project report and presentation.

## Key Business Questions

* Which customer segments contribute the most to overall sales?
* What are the most popular product categories?
* How do customer demographics influence purchasing behavior?
* What factors influence customer spending and purchase frequency?
* How do discounts, subscriptions, and customer loyalty relate to shopping patterns?
* What business strategies can improve customer retention and sales?
